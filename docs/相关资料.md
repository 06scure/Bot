## 环境事实

以下结果来自本地手册与官方发布记录，用于确定编译与部署基线。

| 项 | 结论 | 来源 |
|---|---|---|
| 板卡系统 | Ubuntu 20.04 (focal)，内核 4.19.232-23 | 本地手册第 2 章 |
| 板端编译器 | GCC 9.4.0，野火推荐板卡上直接编译 | 本地手册第 22 章 |
| glibc | 2.31-0ubuntu9.x（arm64） | Launchpad 发布记录 |
| GCC 10 可用性 | focal 仓库提供 gcc-10 10.5.0，属 universe | Launchpad 发布记录 |
| 播放设备 | `card 0` HDMI，`card 1` rockchip,rk809-codec | 本地手册第 37 章 |
| 摄像头 | `ov8858` 等为受支持 MIPI 摄像头，节点以 `v4l2-ctl` 为准 | 本地手册第 32 章 |
| 文件传输 | 手册给出 MobaXterm、FileZilla、NFS、TFTP 四种方式 | 本地手册第 19 章 |
